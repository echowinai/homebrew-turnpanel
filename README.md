# TurnPanel Homebrew tap

Install [TurnPanel](https://turnpanel.com/), the local-first AI workspace, on macOS:

```bash
brew install --cask echowinai/turnpanel/turnpanel
```

Apple Silicon, macOS 13 or later. After the first install TurnPanel updates itself.

Want nightly builds? Install as above, then switch to Nightly in Settings → Updates. TurnPanel follows that stream from then on, and `brew upgrade` leaves a newer build alone.

TurnPanel is in early beta and the macOS build is not yet notarized by Apple. The cask clears the macOS quarantine flag on the app after installing it, so it opens without a Gatekeeper prompt. If you would rather not have that done for you, download the DMG from [turnpanel.com](https://turnpanel.com/) instead.

`Casks/turnpanel.rb` is generated by TurnPanel's release pipeline each time a build is promoted to beta. Please do not edit it by hand.
